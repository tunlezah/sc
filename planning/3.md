# Deliverable 3: 10-Band Parametric EQ Routing to Speakers

## Overview / Goal

Process Bluetooth audio through a 10-band parametric equalizer before it reaches the speakers. The EQ is implemented as a PipeWire filter-chain subprocess, not in-process DSP. On EQ parameter changes, the filter-chain is restarted with an updated config file (~200ms dropout acceptable).

## Technical Approach

**Strategy:** Use PipeWire's `pipewire-filter-chain` as a subprocess. Write a dynamically-generated config file. Spawn the process. On EQ update: kill the process, rewrite the config, respawn.

**Audio routing:**
1. Create a null sink `soundsync-capture` via `pactl load-module module-null-sink`.
2. Write filter-chain config to `$XDG_RUNTIME_DIR/soundsync/filter-chain.conf`.
3. Spawn `pipewire -c <path>`.
4. The filter-chain creates `effect_input.soundsync-eq` (Audio/Sink) and `effect_output.soundsync-eq` (Stream/Output/Audio).
5. WirePlumber routes `bluez_input.*` to `effect_input.soundsync-eq`.

## Step-by-Step Implementation Tasks

1. Implement `EqBand` and `FilterType` with gain clamping to [-12.0, 12.0].
2. Implement biquad coefficient calculation per Audio EQ Cookbook (peaking, low_shelf, high_shelf).
3. Implement preset management (7 built-in: Flat, Bass Boost, Vocal, Classical, Rock, Electronic, Podcast).
4. Implement `FilterChainManager::generate_config` producing PipeWire filter-chain config.
5. Implement null sink creation via `pactl load-module module-null-sink`.
6. Implement filter-chain process lifecycle (kill/write/spawn).
7. Ensure `XDG_RUNTIME_DIR` is set.
8. Wire `SystemEvent::EqChanged` handling.

## Known Pitfalls

| Pitfall | Mitigation |
|---------|------------|
| Invalid `media.class` arg to pactl | Use `sink_properties=device.description=...` NOT `media.class`. |
| Filter-chain output goes nowhere | Always set `playback.props.node.target = "soundsync-capture"`. |
| `XDG_RUNTIME_DIR` unset | Check and set explicitly in startup sequence. |
| ~200ms dropout on EQ change | Acceptable per spec. Use atomic file writes. |

## Acceptance Criteria

1. Null sink `soundsync-capture` created and visible in `pactl list sinks`.
2. Filter-chain process starts and creates PipeWire nodes.
3. Bluetooth audio routes through EQ to speakers.
4. Changing EQ gains causes filter-chain restart with new values.
5. Audio dropout during EQ change under 500ms.
6. EQ bypass routes audio directly without filter-chain.
7. All presets produce correct filter configs.
8. Custom presets can be saved/loaded from disk.
