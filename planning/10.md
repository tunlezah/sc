# Deliverable 10: Installer Script

## Overview / Goal

Create `install.sh` that takes a fresh Linux system (Debian/Ubuntu or Raspberry Pi OS) and configures everything needed to run SoundSync.

## Installer Phases

1. **System detection and conflict check** -- detect distro, check for conflicting BT agents
2. **Install system dependencies** -- PipeWire, BlueZ, WirePlumber, build tools, Rust, Node.js
3. **Configure Bluetooth** -- `/etc/bluetooth/main.conf` with Class=0x24043C, DiscoverableTimeout=0
4. **Build SoundSync** -- `cargo build --release`, `npm run build`
5. **Create systemd service** -- After=bluetooth+pipewire, User=soundsync, Group=audio
6. **XDG_RUNTIME_DIR setup** -- `loginctl enable-linger soundsync`

## File Structure

```
install.sh                   -- Main installer
scripts/
  soundsync.service          -- systemd unit file template
```

## Key Configuration

```ini
# /etc/bluetooth/main.conf
[General]
Class = 0x24043C
Name = SoundSync
DiscoverableTimeout = 0
PairableTimeout = 0
Discoverable = true
Pairable = true

[Policy]
AutoEnable = true
```

```ini
# soundsync.service
[Unit]
Description=SoundSync Bluetooth Audio Receiver
After=bluetooth.service pipewire.service

[Service]
Type=simple
User=soundsync
Group=audio
ExecStart=/opt/soundsync/target/release/soundsync
Environment=XDG_RUNTIME_DIR=/run/user/%U
Environment=RUST_LOG=info
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

## Known Pitfalls

| Pitfall | Mitigation |
|---------|------------|
| `clang stdbool.h` error | Install `libclang-dev`. |
| `snd-aloop` interferes | Detect and warn, don't auto-remove. |
| Conflicting BT agents | Check for bluealsa, warn user. |
| `XDG_RUNTIME_DIR` missing | Set in service file + `loginctl enable-linger`. |

## Acceptance Criteria

1. Installer works on fresh Raspberry Pi OS (Bookworm).
2. `systemctl status soundsync` shows active.
3. Adapter is discoverable.
4. Web UI accessible at `http://<ip>:8080`.
5. Script is idempotent. `shellcheck` passes.
