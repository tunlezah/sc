# Deliverable 8: Pass cargo build/test/clippy/fmt (Quality Gates)

## Overview / Goal

Establish a zero-warnings policy. All code must pass `cargo fmt --check`, `cargo clippy -- -D warnings`, `cargo build`, and `cargo test` before being committed. Comprehensive unit tests must cover DSP math, API endpoints, WebSocket protocol, and EQ pipeline logic.

## Technical Approach

Pre-commit hook + inline unit tests + integration tests.

## File Structure

```
.githooks/
  pre-commit              -- Runs cargo fmt --check && cargo clippy -- -D warnings
tests/
  api_tests.rs            -- Integration tests for REST endpoints
  websocket_tests.rs      -- Integration tests for WebSocket protocol
  eq_pipeline_tests.rs    -- Integration tests for EQ config generation
src/
  test_helpers.rs         -- Mock AppStateHandle, test fixtures
```

## Required Test Coverage

- **DSP/biquad math:** coefficients for known inputs, zero gain = unity, shelf behavior
- **EQ pipeline:** gain clamping, config generation, filter type mapping, preset loading
- **API endpoints:** all 18 return correct status codes, valid/invalid body handling
- **WebSocket:** state_snapshot on connect, event propagation
- **Device state machine:** valid/invalid transitions, serialization

## Step-by-Step Implementation Tasks

1. Create `.githooks/pre-commit` script.
2. Create `src/test_helpers.rs` with factory functions.
3. Write unit tests in each module (`#[cfg(test)] mod tests`).
4. Write integration tests in `tests/`.
5. Use `--test-threads=1` for system resource sharing.
6. Add `RUSTFLAGS="-D warnings"`.

## Acceptance Criteria

1. `cargo fmt --check` passes.
2. `cargo clippy -- -D warnings` passes.
3. `cargo build` succeeds with zero warnings.
4. `cargo test --test-threads=1` passes.
5. Pre-commit hook rejects violations.
6. 20+ unit tests, 5+ integration tests.
